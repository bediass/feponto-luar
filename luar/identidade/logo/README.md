# Logo — Luar Acessórios

Suba aqui os arquivos do logo da Luar.

## O que subir (ideal)

- `logo-principal.svg` — **vetor** (preferência #1; escala sem perder qualidade)
- `logo-branco.svg` — versão em branco/clara pra usar sobre fundo escuro
- `logo-simbolo.svg` — só o símbolo/ícone (pra favicon, avatar, selo)
- PNG com **fundo transparente** também serve, em alta resolução, se não tiver vetor

## Nomeando

Curto e sem espaço/acento: `logo-principal.svg`, `logo-branco.svg`, `logo-simbolo.svg`.

Quando os arquivos chegarem, eu atualizo o `identidade/design-guide.md` com as regras de uso
(área de proteção, tamanho mínimo, fundos) e já ligo o logo no site.
